This project implements and measures a small Fashion-MNIST adaptation of the
StarNet block from **Rewrite the Stars** (Ma et al., CVPR 2024). Codex generated
the adaptation, training pipeline, plotting code, and analysis in this session.
The original paper's reported scores are not used as our experimental results.

## Run

Python 3.11 or newer, with a compatible PyTorch installation, is recommended.
The recorded environment's exact versions are in `requirements.txt` and
`results/metadata.json`.

```sh
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python train.py --device auto
python plot_results.py
```

The default run is all six experiments: operations `star` and `sum` paired at
seeds 42, 43, and 44, each for five epochs. The script downloads the official
Fashion-MNIST files from the dataset's GitHub repository and checks their MD5s
through torchvision. This needs an internet connection on first use.
All data and results paths are relative to the source files, independent of the
working directory. Rerunning overwrites the same results directory; use
`--output other_results` to preserve the supplied results (`plot_results.py`
reads `results/` by default). CPU and CUDA are supported through `--device`.

## Architecture

Input is `B × 1 × 28 × 28`. The stem is a 3×3, stride-1 convolution from 1 to
16 channels, batch normalization, and ReLU6. Stage 1 has one 16-channel block
at 28×28. Stage 2 uses a 3×3 stride-2 convolution and batch normalization from
16 to 32 channels followed by one block at 14×14. Stage 3 similarly uses
32 to 64 channels and one block at 7×7. Final batch normalization, global
average pooling, and a 64-to-10 linear classifier produce logits.

Each residual block is:

1. 7×7 depthwise convolution and batch normalization.
2. Two independent 1×1 convolutions, each expanding C to 2C channels.
3. `ReLU6(branch1) * branch2` (star) or `ReLU6(branch1) + branch2` (sum).
4. 1×1 projection to C and batch normalization.
5. 7×7 depthwise convolution; add the original block input.

All convolutions have biases, matching the official implementation's convention.
There is no dropout, stochastic depth, layer scale, pretrained initialization,
augmentation, scheduler, or exponential moving average. PyTorch's default
Conv2d/Linear initializers are used. Both operation modes have **68,762 trainable
parameters** and an identical state dictionary layout.

## Experimental protocol

- Original training split: 60,000 images. NumPy generator seed 2026 shuffles
  original indices within each class, taking 1,200 per class for training and
  the next 200 for validation. This gives 12,000/2,000 balanced examples and
  leaves 46,000 original training examples unused.
- Official test split: all 10,000 images, 1,000 per class; never used for
  hyperparameter or checkpoint selection.
- Input preprocessing: float32 pixels divided by 255, no other normalization
  and no augmentation.
- Five epochs, batch size 128 (94 training batches/epoch; last batch smaller),
  AdamW learning rate 0.001, weight decay 0.0001, betas (0.9, 0.999), epsilon
  1e-8, cross-entropy loss; no learning-rate scheduler.
- Paired random seeds: 42, 43, 44. Both modes use exactly the same initial
  model tensors and epoch permutations for each seed. Each epoch permutation
  is generated by a CPU torch generator seeded with `seed + 10000`.
- Select the checkpoint with highest validation accuracy (earliest epoch for
  ties), then evaluate the test set once per model. No choices are made using
  test scores.
- Accuracy is correct/total; macro-F1 is the unweighted mean of ten class F1
  scores. Sample standard deviation across seeds uses `ddof=1`.
- Timing includes training and validation plus best-state CPU copying, while
  test time is measured separately. It is local wall-clock runtime, not a
  deployment latency benchmark or a reliable cross-model speed comparison.

## Evidence and verification

`results/metadata.json` records versions, hardware, settings, and timing.
`results/data_manifest.json` records raw-download SHA256s and split-index hashes;
`results/split_indices.npz` contains the exact original indices. Assertions check
class balance, disjoint train/validation indices, expected test size, output
shape, finite gradients, and exact matching initial state hashes.

`results/results.json` contains each model's measured test loss, accuracy,
macro-F1, confusion matrix, and class recalls; `results/summary.json` aggregates
the runs. CSVs expose exact metrics and training curves. Six `*_best.pt` files
contain the selected state dictionaries; these use PyTorch's state-dict format.

Seeds are fixed, but deterministic algorithms are **not** forced: backend
floating-point kernels can vary across machines and software versions. This is
a small controlled classroom experiment, not an ImageNet reproduction or proof
of general superiority. The same hyperparameters for both modes control the
comparison but may not be optimal for either mode. Three seeds describe observed
variation; their standard deviation is not a confidence interval.

## Figures

## Recorded results (20 September 2026)

The six measured runs used an Apple M4, macOS 15.5, and the PyTorch MPS backend.
Every model's validation-selected checkpoint was epoch 5.

| Operation | Seed | Validation accuracy | Test accuracy | Macro-F1 |
|---|---:|---:|---:|---:|
| Star | 42 | 87.45% | 86.78% | 0.8678 |
| Sum | 42 | 86.60% | 85.77% | 0.8581 |
| Star | 43 | 85.95% | 85.14% | 0.8525 |
| Sum | 43 | 82.00% | 81.61% | 0.8137 |
| Star | 44 | 86.35% | 86.05% | 0.8598 |
| Sum | 44 | 85.55% | 85.14% | 0.8500 |

Star test accuracy was **85.99% ± 0.82 percentage points** (mean ± sample SD);
sum was **84.17% ± 2.24 percentage points**. Star was ahead by 1.01, 3.53,
and 0.91 points in the respective seed pairs, averaging 1.82 points. These
results favor multiplication under this particular short training protocol;
they do not establish statistical significance or general superiority.
The six runs' training-plus-validation times were 17.37–19.02 seconds each;
the entire program, including download/loading overhead, took 143.38 seconds.
